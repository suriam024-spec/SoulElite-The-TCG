# SoulElite The TCG — Rule Book ฉบับร่าง 0.6

วันที่ 30 ต.ค. 2026 เมื่อสองฝั่งขัดกัน ถือตาม Rule Book เป็นหลัก ไม่ใส่การ์ดรายใบ

**ป้ายสถานะ:** [ยืนยัน] ตกลงแล้ว / [ชั่วคราว] ค่าตั้งต้นสำหรับเทส หรือข้อที่ผู้เขียนสรุปเองและรอยืนยัน / [แนวคิด] ยังไม่ตายตัว / [รอกำหนด] ยังไม่มีกฎ ห้ามเดา

**ขอบเขตเฟสแรก:** ยูนิต เวทปกติ Supply อาวุธ Fast Spell และ Impact โจมตี/ป้องกัน ส่วนที่เลื่อนออกอยู่ในหมวด 14

## 1. ภาพรวมของเกม

เกมการ์ดต่อสู้ 2 คน ผู้เล่นใช้ยูนิต เวท Fast Supply อาวุธ และ Impact โจมตีคู่ต่อสู้ ป้องกันตัวหลัก บริหารโทเคนกับ Heart Token และสร้างคอมโบ ตอนนี้มี 9 เผ่า ได้แก่ มนุษย์ ปีศาจ พืช บีส เงือก วิหก จอมเวทย์ แมลง และสัตว์เลื้อยคลาน แต่ละเผ่ามีเอกลักษณ์ จุดแข็ง จุดอ่อน และโอกาสชนะที่สมเหตุสมผล ไม่ต้องเก่งเท่ากันทุกสถานการณ์

### 1.1 เงื่อนไขแพ้ [ยืนยัน]

- Life เหลือ 0 แพ้ทันที Life ลดเหลือ 0 ได้จากการโจมตี หรือจากการ์ดที่ยิง Life โดยตรง (คอสต์ค่อนข้างแพง)
- ไม่สามารถจั่วการ์ดใน Draw Phase ได้

การจั่วจากความสามารถในช่วงอื่นของเทิร์นจั่วได้เท่าที่มีในเด็ค จั่วไม่ครบไม่ทำให้แพ้ ข้อความการ์ดอาจเพิ่มเงื่อนไขชนะหรือแพ้ได้

### 1.2 ค่าเริ่มต้น

- Life เริ่มต้น 10 [ชั่วคราว]
- มือเริ่มต้น 5 ใบ [ชั่วคราว]
- โทเคนเริ่มต้น "ราว 5 เม็ด" เป็นค่า config ปรับตามผลเทส [ชั่วคราว]
- จั่ว 1 ใบต่อเทิร์น ผู้เล่นคนแรกไม่ข้ามจั่ว [ยืนยัน]
- ผู้เล่นคนแรกโจมตีไม่ได้ในเทิร์นแรกของตัวเอง เป็นข้อจำกัดเดียวของเทิร์นนั้น ผู้เล่นคนที่สองโจมตีได้ตั้งแต่เทิร์นแรกของตน [ยืนยัน]
- ไม่มีเพดานจำนวนการ์ดในมือ เพดานอาจมาจากความสามารถของการ์ดบางใบ ไม่ใช่กฎกลาง [ยืนยัน]

### 1.3 Life [ยืนยัน]

Life เพิ่มได้ยากมาก มี Supply หายากไม่กี่ใบที่เปลี่ยน Heart Token กลับเป็น Life ด้วยคอสต์สูงมาก การเสีย Life ไม่ได้แปลว่าแพ้เสมอเพราะได้ Heart Token แต่ไม่ถือว่าเป็นผลดีโดยไม่มีข้อแลกเปลี่ยน

## 2. การสร้างเด็ค

### 2.1 ขนาดและจำนวนใบ [ยืนยัน]

เด็คมี 40-60 ใบ ชื่อเดียวกันใส่ได้ไม่เกิน 3 ใบ Supply ชื่อเดียวกันใส่ได้ 1 ใบ แต่ใส่ Supply ต่างชื่อกันกี่ชื่อก็ได้

### 2.2 เผ่า [ยืนยัน]

การ์ดทุกใบมีเผ่ากำกับ 1-2 เผ่า ผสมเผ่าในเด็คเดียวกันได้ การ์ดสองเผ่าเป็นสะพานเชื่อมแนวทางเล่น ข้อจำกัดเรื่องเผ่าเป็นไปตามข้อความการ์ดแต่ละใบ ไม่ใช่ข้อห้ามผสมเผ่าทั่วไป

### 2.3 ผู้บุกเบิก [ยืนยัน]

ผู้บุกเบิกเป็นการ์ดตัวหลักเริ่มต้นพิเศษ ใช้กำหนดตัวเริ่มของเกมเท่านั้น คล้ายตัวเริ่มของ Cardfight Vanguard

- ตอนสร้างเด็คต้องมีผู้บุกเบิกอย่างน้อย 1 ใบ
- ผู้บุกเบิกมี DEF สูงมาก ATK ต่ำ บางใบมีความสามารถ บางใบไม่มี
- ความสามารถของผู้บุกเบิกทำงานเมื่ออยู่ที่ตัวหลัก (M) หรือใน Soul เป็นค่าปกติ เว้นแต่ความสามารถการ์ดระบุให้ทำงานที่ช่อง R/L/S ผู้บุกเบิกมี 2 กลุ่ม คือกลุ่มที่ถูก Ride ทับแล้วอยู่ใน Soul กับกลุ่มที่ถูก Ride ทับแล้วย้ายไปช่อง R/L/S ตามที่การ์ดระบุ
- ใส่ผู้บุกเบิกเกิน 1 ใบได้
- ความสามารถผู้บุกเบิกไม่นับเป็นความสามารถของการ์ดทั่วไป ตัวผู้บุกเบิกเป็นแค่ตัวหลักเริ่มต้น
- ผู้บุกเบิกนับรวมในเด็ค 40-60 ใบ ตอนเริ่มเกมผู้เล่นเลือก 1 ใบจากเด็ควางที่ M ก่อนจั่วมือเริ่มต้น จึงไม่มีกรณีมือเริ่มต้นไม่มีผู้บุกเบิก ใบที่เหลือในเด็คอยู่ตามปกติ

### 2.4 เอซ [ยืนยัน]

"เอซ" เป็นเพียงชื่อเรียกรวมของตัวหลักประจำสาย (เหมือนที่ตัวละครในอนิเมะการ์ดเรียกกัน) ไม่ใช่ระดับหรือกลไกกฎ

## 3. สนามและโซน

### 3.1 ช่องบนสนาม [ยืนยัน]

แต่ละฝั่งมี 6 ช่อง จัดเป็นรูปหัวลูกศร ตัวหลักอยู่หน้าสุด

| ตำแหน่ง | ช่อง | หน้าที่ |
| --- | --- | --- |
| M (Main Zone) | 1 | ตัวหลัก ใช้ต่อสู้และ Ride ไม่ถูกทำลายจากการต่อสู้ ย้ายไม่ได้ |
| L | 1 | ยูนิตข้างซ้าย |
| R | 1 | ยูนิตข้างขวา |
| S | 3 (ซ้าย กลาง ขวา) | ยูนิตสนับสนุน และ Fast ที่เซ็ตคว่ำ ใช้ร่วมกัน |

- ตัวหลักถูกทำลายไม่ได้ (ตอนนี้มีแต่ลดพลัง) คำว่า "ยูนิต" ในข้อความการ์ดรวมตัวหลักด้วย แต่ตัวหลักไม่ถูกทำลาย ความสามารถส่วนใหญ่ระบุช่อง R/L/S ตรง ๆ อยู่แล้ว
- "ซ้าย/ขวา" ในข้อความการ์ดหมายถึงซ้าย/ขวาจากมุมมองของเจ้าของฝั่งที่ถูกอ้างถึง เช่น ยิง L ของอีกฝ่าย คือ L ในมุมมองของอีกฝ่าย
- ช่อง S ใช้ร่วมกันระหว่างยูนิตกับ Fast ที่เซ็ตคว่ำ ถ้าเต็มต้องเอาใบเดิมออกก่อนจึงวางใบใหม่ได้ จำนวน Fast ที่เซ็ตพร้อมกันได้สูงสุดเท่าจำนวนช่อง S ที่ว่าง

### 3.2 การขวางการโจมตี [ยืนยัน]

- ยูนิตข้างทั่วไปไม่ขวางการโจมตีตัวหลัก
- ถ้า L/R ไม่มียูนิตป้องกัน โจมตีตัวหลักได้ทันที
- ถ้ามียูนิตป้องกัน ต้องจัดการมันก่อน (เป็นเป้าหมายบังคับ) ยูนิตป้องกันที่อ่อนแรงอยู่ยังขวางได้ตามปกติ ถ้ามียูนิตป้องกันทั้ง L และ R ผู้โจมตีเลือกจัดการฝั่งใดก่อนก็ได้

### 3.3 บทบาทของยูนิต [ยืนยัน]

ตำแหน่งบนการ์ด (โจมตี / ป้องกัน / สนับสนุน) เป็นตำแหน่งประจำตัวการ์ด ไม่จำกัดว่าลงช่องไหนหรือย้ายไปช่องไหน

- ยูนิตตำแหน่งโจมตีมักมี ATK สูงกว่า และมีสกิลเมื่อโจมตีที่ให้ผลตอบแทน "ตีทุกครั้ง" เป็นเอกลักษณ์ของเกม ไม่ใช่จุดบกพร่อง
- ยูนิตตำแหน่งป้องกันมัก ATK ต่ำ DEF สูงแต่ไม่สูงจนเจาะไม่ได้ หน้าที่คือซื้อเวลา ป้องกันการโจมตีได้เมื่ออยู่ L/R เท่านั้น อยู่ S ไม่ได้
- ยูนิตตำแหน่งสนับสนุนโจมตีได้เมื่ออยู่ L/R แต่ ATK ไม่สูงมาก พอ ๆ กับยูนิตป้องกันหรือน้อยกว่า ยูนิตที่อยู่ S โจมตีเองไม่ได้ (ต้องย้ายขึ้น L/R ก่อน) [ยืนยัน]

### 3.4 การย้ายตำแหน่ง [ยืนยัน]

- ย้ายได้ใน Main Phase ของเทิร์นตัวเอง ความสามารถอาจย้ายนอก Main Phase ได้ ย้ายกี่ครั้งก็ได้ ไม่มีคอสต์
- ย้ายได้เฉพาะแนวตั้งตามคอลัมน์ในผัง: L ↔ S ซ้าย และ R ↔ S ขวา
- M และ S กลางย้ายไม่ได้ S กลางวางแล้ววางเลย หรือเอาออกเท่านั้น
- ย้ายไปช่องที่มียูนิตอยู่ = สลับที่
- การย้ายไม่ทำให้ยูนิตกลับมาพร้อมใช้งานอัตโนมัติ

### 3.5 การลงยูนิตและการเอาออก [ยืนยัน]

- ลงยูนิตลง L/R/S ที่มียูนิตอยู่แล้ว ต้องเอาใบเดิมออกก่อน โดยส่งไป Trash (นับเป็นการส่งไป Trash ไม่ใช่ "ถูกทำลาย" จึงไม่ทริกเกอร์ "เมื่อถูกทำลาย")
- ผู้เล่นเอายูนิตของตัวเองออกโดยไม่ลงใบใหม่ได้ใน Main Phase ไม่มีคอสต์ (ไม่ค่อยคุ้ม เอาออกเพื่อลงใบใหม่มักดีกว่า)
- อาวุธที่ติดอยู่กับยูนิตนั้น และ Fast ที่ถูกเอาออกจาก S เพื่อเปิดที่ ไป Trash ด้วย
- ยูนิตที่เพิ่งลงสนามโจมตีได้ทันที ถ้าอยู่ในตำแหน่งที่โจมตีได้และอยู่ใน Attack Phase

### 3.6 โซนอื่น

| โซน | หน้าที่ |
| --- | --- |
| Deck | กองจั่ว จั่วจากด้านบน |
| Hand | มือ ไม่มีเพดาน |
| Life | ค่าชีวิต |
| Token | โทเคนธรรมดาและ Heart Token อยู่รวมกัน |
| Trash Token | โทเคนที่ใช้แล้ว กลับมาใน Reset Phase |
| Trash / Drop Zone | สุสาน ค่าหลักของการ์ดที่ใช้แล้ว ถูกทำลาย หรือถูกส่งไป |
| Void | นำการ์ดออกตามความสามารถเฉพาะ แยกจาก Trash ชัดเจน |
| Soul Zone | การ์ดที่ถูก Ride ทับจากตัวหลัก ใช้เป็นต้นทุนได้ แสดงซ้อนใต้ M |

**Void:** การ์ดใน Void ทำงานเองไม่ได้ เว้นแต่ความสามารถหรือกฎอนุญาต การ์ดที่ถูกทำให้ไร้ความสามารถยังมีชื่ออยู่ จึงยังนับในเงื่อนไขนับชื่อ

**Soul Zone:** Ride ซ้ำเพิ่มจำนวน Soul ผู้เล่นเลือก Soul ที่จะจ่าย ใบที่จ่ายไป Trash

**การกลับเด็ค:** หมายถึงกลับใต้กองเสมอ ผู้เล่นจัดลำดับเอง เว้นแต่จะระบุว่าสับกอง

## 4. การเปิดเกม

1. เป่ายิ้งฉุบ ผู้ชนะเลือกเล่นก่อนหรือหลัง [ยืนยัน] บนเวอร์ชันเว็บใช้การสุ่มแทน [ยืนยัน]
2. แต่ละฝั่งเลือกผู้บุกเบิก 1 ใบจากเด็ค วางคว่ำที่ M ก่อนจั่วมือ [ยืนยัน]
3. จั่วมือเริ่มต้น 5 ใบ [ชั่วคราว]
4. Mulligan ได้ครั้งเดียว [ยืนยัน] เปลี่ยนกี่ใบก็ได้ ใบที่เปลี่ยนกลับเด็คก่อน (กลับใต้กองตามข้อ 3.6 ไม่สับเด็ค) แล้วจึงจั่วทดแทนเท่าจำนวนที่เอากลับ [ยืนยัน]
5. ผู้บุกเบิกของทั้งสองฝั่งเปิดพร้อมกัน [ยืนยัน]
6. เริ่มเทิร์นแรกของผู้เล่นคนแรก

## 5. ทรัพยากร

### 5.1 โทเคนธรรมดา

เริ่มราว 5 เม็ด [ชั่วคราว] ได้ +1 เม็ดต่อเทิร์นใน Draw Phase รวมเทิร์นแรกด้วย [ยืนยัน] ไม่มีเพดาน แหล่งเพิ่มอื่นมีน้อยมาก ใช้แล้วไป Trash Token และกลับมาตอน Reset Phase

### 5.2 โทเคนที่ล็อกบนการ์ด [ยืนยัน]

ยูนิตบางตัวต้องถือโทเคนจึงใช้สกิลหรือโจมตีได้ Fast ต้องวางโทเคนอย่างน้อย 1 เม็ดจึงใช้ในเทิร์นอีกฝ่ายได้ อาวุธต้องมีโทเคนวางคู่ 1-3 เม็ดหรือ Heart Token โทเคนที่ใช้ได้จริง = ทั้งหมด − ที่ล็อกอยู่ − ที่ใช้ไปแล้วในเทิร์นนี้ โทเคนที่ล็อกแสดงเป็นป้ายบนการ์ดนั้น ไม่มีโซนแยก

### 5.3 Heart Token [ยืนยัน]

- ได้ 1 เม็ดต่อ Life ที่เสีย ได้ทันทีและใช้ต่อได้ทันที รวมถึงกรณีจ่าย Life เป็นต้นทุนของความสามารถ และ Life ที่หายจากการ์ดยิง Life โดยตรง
- เก็บในโซน Token เดียวกับโทเคนธรรมดา ใช้แล้วลง Trash Token กลับตอน Reset Phase สะสมข้ามเทิร์นได้
- จ่ายแทนโทเคนธรรมดาได้ 1:1 โทเคนธรรมดาแทน Heart Token ไม่ได้
- ใช้เรียกยูนิตระดับสูง สกิล การป้องกัน และ Impact
- การ์ดบางใบมีต้นทุนจ่าย Heart Token ถาวร โทเคนนั้นออกจากเกม ไม่กลับตอน Reset

### 5.4 Heart ขั้นต่ำ [ยืนยัน]

ข้อกำหนดแยกจากคอสต์ คือจำนวน Heart Token ที่ต้องมีจึงเล่นการ์ดหรือใช้ความสามารถได้ นับเฉพาะ Heart Token ที่ใช้ได้ตอนนี้ (ไม่ถูกล็อก และยังไม่ได้ใช้ไปในเทิร์นนี้) การลดคอสต์และการ "ไม่จ่ายคอสต์" ไม่ลดหรือข้าม Heart ขั้นต่ำ เว้นแต่ข้อความการ์ดระบุชัด

### 5.5 การจ่าย Life เป็นต้นทุน [ยืนยัน]

บางความสามารถจ่าย Life เป็นต้นทุน นับเป็นการเสีย Life (ได้ Heart Token) บางใบคืน Life ที่จ่ายไปตอนจบเทิร์นตามข้อความการ์ด จ่าย Life ไม่ได้ถ้าจ่ายแล้ว Life จะต่ำกว่า 1 ดังนั้นแพ้ได้จากการถูกโจมตีหรือถูกยิง Life เท่านั้น ไม่ใช่จากการจ่ายต้นทุนเอง

### 5.6 การยิง Life โดยตรง [ยืนยัน]

Life ที่หายจากการ์ดยิงตรงให้ Heart Token แก่ผู้เสียเท่าเดิม แต่ไม่นับเป็นการโจมตี จึงไม่ทริกเกอร์ "เมื่อโจมตีเข้า Life" ส่วนความสามารถที่เขียนว่า "เมื่อ Life ของอีกฝ่ายลด" ทำงานได้แม้ไม่ใช่การโจมตี

## 6. โครงสร้างของเทิร์น

ลำดับ: Start → Reset → Draw → Ride → Main → Attack → End โดย Impact เป็นช่วงภายใน Attack Phase

- **Start:** ความสามารถที่ทำงานเมื่อเริ่มเทิร์น พิจารณาตัวหลักก่อน ที่เหลือเรียงตามที่ผู้เล่นเลือก
- **Reset:** ยูนิตอ่อนแรงของตัวเองกลับมาพร้อมใช้งาน โทเคนทุกชนิดรวม Heart Token ที่ใช้แล้วกลับจาก Trash Token ผลที่ห้ามฟื้นพลังยังมีผลตามที่การ์ดระบุ
- **Draw:** ได้ +1 โทเคน แล้วจั่ว 1 ใบ จั่วไม่ได้คือแพ้
- **Ride:** วางการ์ดทับตัวหลัก ทำได้ 1 ครั้งต่อเทิร์น (ดูข้อ 6.1)
- **Main:** เล่นยูนิต เวท Supply อาวุธ ใช้ความสามารถ ย้ายตำแหน่ง เอายูนิตออก จัดการทรัพยากร ตราบที่ผ่านเงื่อนไขและจ่ายต้นทุนครบ
- **Attack:** ทุกยูนิตรวมตัวหลักที่พร้อมและอยู่ตำแหน่งโจมตีได้ โจมตีในเฟสนี้ ดูหมวด 7
- **End:** ผลที่มีจนจบเทิร์นสิ้นสุด และความสามารถ "เมื่อจบเทิร์น" ทำงาน

### 6.1 Ride [ยืนยัน]

- Ride ใช้การ์ดจากมือเป็นหลัก เว้นแต่ความสามารถระบุแหล่งอื่น ตัวหลักต้องเป็นยูนิตเท่านั้น
- ไม่มีระบบระดับ เงื่อนไข Ride เขียนบนการ์ดแต่ละใบ ถ้าการ์ดไม่ระบุเงื่อนไข Ride ทับตัวหลักตัวใดก็ได้ รวมถึงทับผู้บุกเบิกตั้งแต่เทิร์นแรกของผู้เล่น
- จ่ายคอสต์ตามที่การ์ดระบุ
- ตัวหลักเดิมไปอยู่ Soul Zone ของใบใหม่ อาวุธที่ติดอยู่ส่งต่อให้ตัวหลักใหม่
- ตัวหลักใหม่ใช้ ATK/DEF/คอร์ของใบใหม่ และพร้อมใช้งาน (ไม่อ่อนแรง) เว้นแต่การ์ดระบุห้ามฟื้นสถานะ จึงโจมตีได้ในเทิร์นที่ Ride

## 7. การต่อสู้

### 7.1 การประกาศและเทียบค่า [ยืนยัน]

1. ประกาศโจมตีด้วยยูนิตที่พร้อมและอยู่ตำแหน่งที่โจมตีได้ (M, L, R) เลือกเป้าหมายตามกฎขวางข้อ 3.2 ยูนิตที่ประกาศโจมตีเปลี่ยนเป็นอ่อนแรงทันที
2. ถ้าการต่อสู้เกี่ยวกับตัวหลัก (ตัวหลักโจมตี หรือถูกโจมตีถึง) ผู้เล่นสลับใช้ Impact ตามหมวด 8 การต่อสู้ของยูนิต L/R ไม่มีช่วง Impact ใช้ Fast และสกิลแทน
3. เทียบ ATK ฝ่ายโจมตีกับ DEF ฝ่ายป้องกัน

- ATK ≥ DEF คือสำเร็จ (เสมอ ฝ่ายโจมตีชนะ) ยูนิตฝ่ายรับถูกทำลาย
- ATK < DEF คือล้มเหลว ไม่เกิดผลใดกับใครทั้งสิ้น
- โจมตีตัวหลักสำเร็จ: ตัวหลักไม่ถูกทำลาย ผู้ถูกตีเสีย Life เท่าคอร์ของยูนิตที่โจมตี และได้ Heart Token เท่า Life ที่เสียทันที

### 7.2 ความสามารถตอนโจมตี [ยืนยัน]

- "เมื่อโจมตี" ทำงานตอนประกาศโจมตี ผู้เล่นเลือกใช้หรือไม่ใช้ก็ได้ ถ้าใช้ต้องจ่ายต้นทุน แม้การโจมตีจะล้มเหลวก็ยังทำงาน
- "เมื่อโจมตีเข้า Life" ต้องทำความเสียหายต่อ Life ได้จริงอย่างน้อย 1 จึงทำงาน ถ้าเป็น 0 (เช่น คอร์ 0) ไม่ทำงาน และไม่ทำงานกับการยิง Life โดยตรง (ข้อ 5.6)
- ถ้ายูนิตที่กำลังโจมตีถูกทำลายก่อนแก้ผล การโจมตีนั้นไร้ผล ผลที่แก้สำเร็จไปแล้วไม่ถูกย้อนกลับ เว้นแต่ความสามารถระบุ ถ้าเป้าหมายถูกทำลายก่อนเทียบค่า การโจมตีไร้ผล เว้นแต่ถูกชุบกลับช่องเดิมตามข้อ 8.2.1 ซึ่งเทียบค่าต่อกับยูนิตที่ถูกชุบได้เลย

### 7.3 สถานะอ่อนแรง [ยืนยัน]

ยูนิตอ่อนแรงโจมตีซ้ำไม่ได้จนกว่าจะถูกฟื้นพลัง (Refresh) ยูนิตที่ถูกฟื้นพลังโจมตีอีกครั้งในเทิร์นเดียวกันได้ เว้นแต่มีข้อจำกัดอื่น

## 8. Impact

### 8.1 ชนิดและต้นทุน [ยืนยัน]

Impact เฟสแรกมี 2 แบบ คือ **โจมตี** (เพิ่ม ATK ทำลาย กดดัน) และ **ป้องกัน** (เพิ่ม DEF กันการทำลาย) ต้นทุนมักเป็นโทเคนผสม Heart Token ส่วนใหญ่ใช้จากมือ ใช้แล้วลง Trash ความสามารถบางใบอนุญาตให้ใช้จากแหล่งอื่น

### 8.2 ลำดับการใช้ [ยืนยัน]

- ใช้ได้เมื่อตัวหลักโจมตีหรือถูกโจมตีถึง
- ฝั่งโจมตีมีสิทธิ์ก่อน แล้วผลัดกัน แต่ละฝั่ง "ใช้" หรือ "pass" ได้ ถ้ามีคนใช้ ฝั่งตรงข้ามได้สิทธิ์ตอบ ฝั่งที่ใช้ไปแล้วใช้ต่อได้อีกถ้าจ่ายต้นทุนไหว (เช่น A ใช้ B ใช้ A ใช้ต่อ) หรือเลือกไม่ใช้ก็ได้
- จบเมื่อ pass ติดกันทั้งสองฝั่ง หรือไม่มีใครตอบได้ ไม่จำกัดครั้งต่อเทิร์น
- ผลของ Impact ดำเนินทันที (ทำลาย เปลี่ยน ATK/DEF ค้นการ์ด) ผลที่เสร็จแล้วไม่ย้อนกลับ ไม่ใช้ลำดับ stack
- Fast แทรกได้ตามหมวด 9

### 8.2.1 ผลทำลายและการชุบ [ยืนยัน]

- ผลของ Impact ออกทันที รวมถึงผลทำลาย Fast ที่มีผลกันการทำลายจึงกันผลทำลายของ Impact ไม่ได้ มีเพียง Impact ป้องกันที่ช่วยได้
- ยูนิตที่ถูกทำลายจาก Impact โจมตีชุบกลับช่องเดิมได้ ด้วย Impact ที่ระบุว่าชุบ โดยต้องใช้ทันทีใน action เดียวกัน เช่น A ใช้ Impact ที่มีผลทำลาย B ต้องใช้ Impact ตอบทันทีเพื่อกันไม่ให้ยูนิตถูกทำลาย
- ถ้า B ไม่ใช้ แล้ว A ใช้ Fast ต่อ หรือ action นั้นผ่านไปแล้ว B ใช้ Impact อื่นต่อได้ แต่ชุบไม่ได้แล้ว
- ยูนิตที่ถูกชุบถือว่าไม่ถูกทำลาย (เหมือนกันการถูกทำลายในระดับเดียวกัน) กลับมาเหมือนก่อนถูกทำลาย (สถานะอ่อนแรง โทเคนที่ล็อก ค่าพลังชั่วคราว) [ยืนยัน] อาวุธกลับมาด้วยเมื่อโทเคนที่ล็อกไว้ยังครบ ถ้าโทเคนถูกใช้ไปแล้วจนไม่พอล็อกกลับ อาวุธอยู่ใน Trash ต่อไป กลับมาแค่ยูนิต ความสามารถ "เมื่อถูกทำลาย" ไม่แสดงผล
- ความสามารถชุบส่วนใหญ่ชุบลงช่องว่าง ถ้าช่องเดิมมียูนิตอื่นอยู่แล้วชุบไม่ได้
- ถ้ายูนิตป้องกันที่ชุบกลับอยู่ L/R ป้องกันได้ทันที
- กรณีขอบอื่นของการชุบ (เช่น ลำดับการกันโทเคนไว้) ไม่มีกฎเพิ่มในเฟสแรก เพราะการชุบเกิดไม่บ่อย ถ้าเจอเคสจริงตอนเทสค่อยเพิ่ม

### 8.3 เคาน์เตอร์ Impact [แนวคิด และเลื่อนออกจากเฟสแรก]

คล้าย Fast ตรงที่ใช้ได้ตามเงื่อนไขการ์ด แต่ไม่ต้องเซ็ตไว้ ถือในมือได้ และสเกลแรงกว่า Fast คอสต์ค่อนข้างสูง อาจเปลี่ยนยูนิตธรรมดาตรงช่อง R/L เป็นยูนิตป้องกัน และมีไอเดียจ่าย Heart Token เพื่อฟื้นโทเคนธรรมดา (ระวังวงวน ฟื้นโทเคนแล้วใช้ Impact ต่อ)

เงื่อนไขการใช้และเป้าหมายของการโจมตีสวนขึ้นกับข้อความการ์ดแต่ละใบ ไม่ต้องมีกฎกลางเพิ่ม

### 8.4 Final Impact [แนวคิดอนาคต]

ใช้ได้เทิร์นละครั้ง ฝ่ายตรงข้ามตอบด้วย Impact ธรรมดาไม่ได้ ต้องตอบด้วย Final Impact เท่านั้น

## 9. Fast และหน้าต่างตอบสนอง

### 9.1 Fast Spell [ยืนยัน]

- ใช้ได้สองทาง ในเทิร์นตัวเอง ใช้จากมือเหมือนเวทปกติ ในเทิร์นอีกฝ่าย ต้องเซ็ตคว่ำไว้ที่ S พร้อมโทเคนอย่างน้อย 1 เม็ดล่วงหน้า (เซ็ตได้ใน Main Phase) และเซ็ตแล้วใช้จาก S ได้ทันที
- จำนวน Fast ที่เซ็ตพร้อมกันได้สูงสุดเท่าจำนวนช่อง S ที่ว่าง
- ใช้สำเร็จไป Trash / ผู้เล่นถอดโทเคนออกเองไป Void และไร้ความสามารถ / ถูกคู่ต่อสู้ทำลายไป Trash (บางใบ Void) สองเหตุการณ์หลังนี้ห้ามปะปนกัน
- Fast ตอบ Fast ได้ทุกสถานการณ์เมื่อเข้าเงื่อนไข ใช้กี่ใบก็ได้ถ้าเข้าเงื่อนไขและจ่ายต้นทุนไหว

### 9.2 เหตุการณ์กลางที่เปิดหน้าต่าง Fast [ชั่วคราว]

การ์ด Fast อ้างอิงเหตุการณ์ในรายการนี้ รายการอาจเพิ่มได้ภายหลัง

- มีการประกาศโจมตี
- ตัวหลักถูกโจมตีถึง
- มีการใช้ Impact
- มีการเล่นยูนิต เวท หรือ Supply (มีการ์ดลง)
- ยูนิตถูกทำลาย

เงื่อนไขเจาะจงอยู่ที่ข้อความการ์ดแต่ละใบ

### 9.3 สิทธิ์ตอบและการแก้ผล [ยืนยัน]

- Fast ทำงาน **ก่อน** ผลของเหตุการณ์นั้นแก้ จึงยกเลิกหรือเปลี่ยนผลได้ ยกเว้นเหตุการณ์ "มีการใช้ Impact" ซึ่ง Impact ออกผลทันที Fast ตอบได้หลังผลออกแล้วเท่านั้น
- ฝั่งที่ไม่ใช่ผู้ทำเหตุการณ์ได้สิทธิ์ตอบก่อน แล้วสลับกัน เมื่อ pass ติดกันทั้งสองฝั่ง จึงแก้ผลย้อนจากใบหลังสุดไปใบแรก แล้วจึงแก้ผลของเหตุการณ์ต้นทาง
- หลาย Fast ซ้อนกัน ใบที่ใช้ทีหลังแก้ก่อน
- Fast กับ Impact แทรกกันได้ในการต่อสู้เดียวกัน แต่ Impact ยังดำเนินผลทันที ส่วน Fast ที่ซ้อนกันใช้ลำดับ stack

## 10. ประเภทการ์ด

### 10.1 ยูนิต

มีเผ่า คอสต์ ATK DEF คอร์ (ส่วนใหญ่ 1-2 ตัวเก่งอาจ 3+) ความสามารถ และตำแหน่งประจำตัว (โจมตี ป้องกัน สนับสนุน) ค่า ATK/DEF

### 10.2 เวทปกติ [ยืนยัน]

ใช้ในช่วง Main ใช้แล้วลง Trash เช่น จั่ว ค้น ทำลาย ลดค่า และสร้างคอมโบ

### 10.3 อาวุธ [ยืนยัน]

- ติดที่ตัวหลักได้ และติดที่ยูนิต R/L/S ได้เช่นกัน ติดได้ 1 ชิ้นต่อยูนิต เว้นแต่ความสามารถระบุให้ติดได้มากกว่า
- ต้องมีโทเคนวางคู่ (1-3 เม็ดหรือ Heart Token) โทเคนที่วางเป็นของผู้เล่นที่มีอยู่แล้ว เก็บไว้จ่ายสกิลได้
- หลุดเมื่อเงื่อนไขโทเคนไม่ครบ เมื่อยูนิตที่ถือถูกเอาออกหรือถูกทำลาย (ยกเว้นตัวหลัก) หรือเมื่อถูกการ์ดที่ระบุทำลายอาวุธ หลุดแล้วไป Trash
- ติดที่ตัวหลัก ส่งต่อให้ตัวหลักใหม่เมื่อ Ride เปลี่ยนอาวุธต้องส่งใบเดิมลง Trash

### 10.4 Supply [ยืนยัน]

- ประเภทแยก ส่วนใหญ่ค้นขึ้นมือไม่ได้ เว้นแต่ข้อความการ์ดอนุญาต
- ส่วนใหญ่ใช้ใน Main บางใบใช้ตอนเข้าเงื่อนไข ใช้แล้วลง Trash
- ชื่อเดียวกันใช้ได้ครั้งเดียวต่อเทิร์น แม้ถูกนำกลับมือหรือย้ายโซน และแม้มีทรัพยากรพอ ต่างชื่อใช้หลายใบได้ถ้าผ่านเงื่อนไขและจ่ายครบ
- การข้ามคอสต์ไม่ยกเลิกข้อจำกัดอื่น เว้นแต่ความสามารถระบุโดยตรง
- Supply ของเผ่าอื่นส่วนใหญ่ไม่ส่งเสริมเผ่าอื่น ส่วน Supply ของมนุษย์ออกแบบให้กลางใช้ได้เกือบทุกเผ่า [แนวคิดออกแบบ]

## 11. ความสามารถและลำดับผล

### 11.1 หลักทั่วไป

ความสามารถมีผลตามข้อความ ภายใต้กฎทั่วไป ถ้าขัดกับกฎทั่วไป ข้อความการ์ดมีผลเฉพาะส่วนที่ขัดกัน การข้ามข้อจำกัด เช่น Supply ซ้ำหรือ Heart ขั้นต่ำ ทำได้เฉพาะเมื่อข้อความระบุตรง ๆ ต้องผ่านเงื่อนไขและจ่ายต้นทุนก่อนใช้

### 11.2 Trigger หลายอันพร้อมกัน [ยืนยัน]

เจ้าของเทิร์นเรียงก่อน แล้วเลือกลำดับเองในฝั่งตัวเอง จากนั้นฝั่งตรงข้ามเรียงลำดับของตน (เหมือน Start Phase ที่ตัวหลักพิจารณาก่อน)

### 11.3 ถ้อยคำมาตรฐาน

- "ยูนิต" กับ "การ์ด" ต่างความหมาย "ยูนิต" รวมตัวหลัก (ดูข้อ 3.1)
- "เมื่อโจมตี" กับ "เมื่อโจมตีเข้า Life" ตามข้อ 7.2
- "เทิร์นละครั้ง" นับต่อใบ เว้นแต่ระบุชื่อว่าใช้ได้เทิร์นละครั้ง
- "เมื่อถูก Mill" ทำงานแม้คู่ต่อสู้เป็นคน Mill การ์ดใบที่ไม่ให้ทำงานต้องระบุเอง [ยืนยัน]
- Mill ค่ากลางส่งการ์ดบนเด็คไป Trash ไป Void เมื่อความสามารถระบุ [ยืนยัน] ห้ามนำการ์ดของอีกฝ่ายมาใช้เป็นหลักทั่วไป ข้อยกเว้นเป็นไปตามข้อความการ์ด
- ซ้าย/ขวา อิงมุมมองของเจ้าของฝั่งที่ถูกอ้างถึง

### 11.4 หมวดความสามารถแบบแผน [ข้อเสนอ]

จั่ว / ค้น / ทำลาย / เพิ่มหรือลดค่า (ATK DEF คอร์ คอสต์) / ส่งไป Trash หรือ Void / กลับเด็ค / เรียกลงสนาม / ฟื้นพลัง / ฟื้นหรือจ่ายโทเคน / ทำให้ไร้ความสามารถ / ย้ายตำแหน่ง / ยิง Life โดยตรง / ทำลายอาวุธ

## 12. ผังสนามและ UI

- ผังสนามตามภาพตัวอย่าง ฝั่งคู่ต่อสู้หมุน 180° ผู้เล่นอ่านการ์ดฝั่งตัวเองถูกทิศ
- กำหนด ID ช่องคงที่ เช่น p1.M p1.L p1.R p1.S1-S3 และ p2.* ให้ตรงกับสถานะผู้เล่น
- Soul Zone แสดงซ้อนใต้ M อาวุธและโทเคนที่ล็อกแสดงเป็นป้ายบนการ์ดนั้น ไม่มีโซนแยก
- Hand เป็นแถบล่างของจอ มือคู่ต่อสู้แสดงเป็นใบคว่ำ
- ช่อง Token แสดงตัวเลข 2 ชนิด (เช่น 3 + ♥2) Life แสดงเป็นตัวเลข

### สถานะที่เอนจินต้องเก็บ

- **การ์ดบนสนาม:** ตำแหน่ง / พร้อมหรืออ่อนแรง / โทเคนที่ล็อก / อาวุธที่ติด / Soul ที่ซ้อนอยู่ / ผลชั่วคราว / ช่อง tags (ว่างไว้ก่อน)
- **ผู้เล่น:** Life / มือ / เด็ค (พร้อมลำดับ) / Token ธรรมดา / Heart Token / Trash Token / Trash / Void / Soul / ตัวหลักและ L R S / รายชื่อ Supply ที่ใช้แล้วในเทิร์นนี้ / ตัวนับในเทิร์น (Ride แล้วหรือยัง ความสามารถเทิร์นละครั้ง)

## 13. คำศัพท์มาตรฐาน

- **Ride:** วางการ์ดทับตัวหลัก 1 ครั้งต่อเทิร์น
- **ผู้บุกเบิก:** ตัวหลักเริ่มต้นพิเศษ DEF สูง ATK ต่ำ ความสามารถปกติทำงานเฉพาะใน M หรือ Soul เว้นแต่การ์ดระบุช่อง R/L/S
- **Soul / Soul Zone:** การ์ดที่ถูก Ride ทับ ใช้เป็นต้นทุนได้
- **Refresh / Exhausted:** ฟื้นพลัง / อ่อนแรง
- **Token / Heart Token / Trash Token:** ตามหมวด 5
- **Trash / Void:** สุสาน / พื้นที่นำออกตามเหตุการณ์
- **Core (คอร์):** จำนวน Life ที่เสียเมื่อตัวหลักถูกโจมตีสำเร็จ
- **Fast:** การ์ดตอบสนอง เซ็ตคว่ำใน S เพื่อใช้ในเทิร์นอีกฝ่าย
- **Impact:** ความสามารถช่วงต่อสู้ของตัวหลัก ดำเนินผลทันที
- **Supply:** ประเภทการ์ดชื่อละ 1 ใบ ใช้ชื่อซ้ำในเทิร์นเดียวไม่ได้
- **Mill:** ส่งการ์ดจากบนเด็คไป Trash หรือ Void ตามข้อความการ์ด
- **กลับเด็ค:** กลับใต้กองเสมอ
